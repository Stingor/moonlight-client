# ro_render — construction de la scène et rendu.
#
# ⚠ Cette bibliothèque ne dépend PAS de `sim`, et ne le fera pas : `app`
# construit une description de données et la remet au renderer. C'est ce qui
# rend le rendu vérifiable hors jeu, par comparaison d'images.
#
# DEUX cibles, et la séparation est délibérée :
#
#   ro_render     maillage, caméra, chargement d'une carte. Aucune dépendance
#                 OpenGL, donc compilable et testable sur le runner Linux de la
#                 CI, avec les sanitizers.
#   ro_render_gl  les pièces qui parlent à la carte graphique.
#
# Tout ce qui peut vivre dans la première y vit. C'est ce qui garde les erreurs
# de convention (axe inversé, cadrage) sous le contrôle de tests numériques
# plutôt que de l'œil.
#
# `ro_render` lit le VFS — le DAG l'y autorise (`render ← core, formats, vfs`).
# C'est ce qui permet à l'outil hors-jeu et à l'application de partager UN seul
# chargeur de carte au lieu d'en entretenir deux.
